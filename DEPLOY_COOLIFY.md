# Coolify

1. Sube este proyecto a GitHub.
2. En Coolify crea un recurso Docker Compose apuntando al repositorio.
3. Expón los puertos 3000 (web) y 8000 (API), o coloca un reverse proxy.
4. Para producción conviene poner web y API detrás del mismo dominio y usar HTTPS.
5. Añade autenticación antes de exponer el API públicamente.
6. Configura límites de auditoría y una allowlist de dominios autorizados.
